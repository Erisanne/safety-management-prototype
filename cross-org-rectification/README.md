# 集团/事业部整改派发 · Web 原型

静态交互原型，用于确认「集团 / 事业部向项目公司派发整改、逐级验收」的 Web 端交互与字段。

打开 `index.html` 即可体验，无需构建、无外部依赖。页面数据为模拟数据，**不构成正式业务结论或验收依据**。

## 状态字典

沿用系统实际状态：`草稿`、`待派单`、`待接单`、`整改中`、`待验收`、`逾期未整改`、`逾期未验收`、`逾期完成`、`已关闭`。

跨组织派发不新增状态：派发后进入 **待派单**（等待责任公司安环部指派部门 / 部门负责人派单）；验收链（验收人 A → 公司安环部 → 上级单位 → 派发单位）在 **待验收** 内部流转，末级通过后置为 **已关闭**（超期则为 **逾期完成**）。

## 覆盖范围（Web 端）

- **状态栏**：左侧分段控件「我派发的 / 我收到的」＋竖线＋状态字典（9 个状态全部展示，按流程顺序：草稿 → 待派单 → 待接单 → 整改中 → 待验收 → 逾期未整改 → 逾期未验收 → 逾期完成 → 已关闭，带数量，为 0 时置灰）＋「全部」；当前项高亮蓝色。
- 列表：工具栏（新增、导入、批量派发、派单、收回、关闭）、关键字检索、表格、分页；默认「当前组织＝海南航天 · 我收到的」，两个视角都有数据。
- **待我审批**：独立菜单（隐患治理 → 待我审批），带数量角标；列出「待验收 / 逾期未验收」且**当前验收节点处理人＝当前登录人**的单据，列表字段：整改单编号、状态、当前验收节点、验收人/审批人、派发方、责任公司、隐患描述、**整改提交时间**、整改期限；可直接点「审批」进入验收；本人审批后单据流转到下一节点，即自动离开待我审批；从待我审批进入详情后，返回仍回到待我审批。
- **新增＝整页表单**（非弹窗）：基础信息（责任公司、渠道分类、来源检查单、风险对象、分析单元、隐患来源、隐患等级、紧急程度、隐患类型、隐患类别、隐患治理类型、级别、隐患描述、现场照片/视频）＋派发信息（整改要求、整改期限、验收人 A、登记人）。
- 详情：
  - 整改单基础信息 ＋ 现场照片 / 现场视频
  - 派发信息（跨组织）
  - 隐患描述与整改要求
  - 整改执行 ＋ 整改后照片 / 整改后视频
  - **验收意见（最新验收结果）**：验收结论、验收单号、验收人、验收部门、验收时间、验收意见、验收照片/视频；下方为验收流程节点（各节点显示验收人、结论与意见）
  - **流转记录**：**倒序**（最新在上），保留全部流转，含驳回后重新提交
  - 执行情况 / 系统信息 / 操作信息
- 操作按钮按状态给出：提交派发 / 接收并指派部门 / 直接指派整改人 / 派单 / 接单 / 退单 / 提交验收 / 验收 / 关闭。
- 驳回：验收时可选择「驳回到发起（整改驳回，退回整改执行人）」或「驳回到已流转节点（验收驳回）」，后者会列出**已流转过的验收节点**供选择，第一验收节点无可退回节点时只能驳回到发起。
- 派单抽屉：沿用现有系统的整改派单表单（整改人 / 整改期限 / 验收人 / 整改要求），并增加来源信息（来源检查单、隐患描述、风险对象）。
- 数据：**33 条**模拟单据，覆盖 集团安全管控 / 特气事业部 / 仓储事业部 / 海南航天 / DME项目 与全部 9 个状态；含公司内部自查发起的整改（派发方＝责任公司）。现场、整改后、验收均含照片与视频（占位图）。

## 全流程演示路径

1. 默认「当前组织＝集团安全管控、我派发的」→ 打开 ZGD20261013001（待派单）。
2. 「接收并指派部门」→ 选整改部门 → 仍在「待派单」（等待部门负责人派单）；点「派单」填整改人／期限／验收人／整改要求 →「待接单」。
3. 「接单」→「整改中」→「提交验收」→「待验收」。
4. 打开左侧菜单「待我审批」→ 点「审批」→ 填验收意见 → 逐级验收：验收人 A → 公司安环部 → 上级单位 → 派发单位，末级通过后置为「已关闭」，**验收意见回填到整单**。
5. 任一级可「驳回」：驳回到发起＝整改驳回（退回整改人，状态回「整改中」）；驳回到节点＝验收驳回，需在弹窗中选择具体的已流转节点。记录见「流转记录」。ZGD20261013004 预置了一条「驳回 → 重新提交」的完整流水。

> 原型为便于演示，各状态按钮都直接可点，不校验当前登录人是否为该节点处理人（详情页顶部提示「当前节点 / 应付方」）。

## 与现有系统的关系

视觉与字段参考现有「九丰 SAFE-LINK 系统」整改单页面：左侧隐患治理 → 整改单，列表页页签 + 状态数量 + 表格，详情页分块折叠 + 执行情况时间线，派单抽屉沿用原表单。

本原型在此基础上新增跨组织能力：派发方组织、责任公司、我派发的 / 我收到的、待我审批菜单、多级验收流程与驳回。

## 待确认项

- 逾期状态由系统按整改期限自动置位（原型不做手工切换，模拟数据中已包含逾期未整改 / 逾期未验收 / 逾期完成样本）。
- 验收人 A 之外各节点验收人的解析规则，以及流程模板配置界面（原型未展开）。
- 批量派发与导入的模板列与校验规则（原型为占位）。
- 附件（照片 / 视频）为占位图，接正式系统时对接真实文件服务。

## 未包含

App / PDA 端（后续单独设计）、流程模板配置页、统计看板、消息通知。
