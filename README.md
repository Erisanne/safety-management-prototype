# 安全作业移动端原型（在线预览）

本仓库仅用于发布可点击的 HTML 原型，全部为模拟数据，不含正式需求、合同、验收资料或真实人员信息。

## 页面

- `index.html`：安全作业移动工作台
- `inspection-crossday.html`：巡检计划跨天任务时间
- `cross-org-rectification/index.html`：集团 / 事业部整改派发（Web 端）

## 集团 / 事业部整改派发（Web 端）

集团、事业部向项目公司派发整改、项目公司逐级指派、验收结果逐级审批并回到派发单位闭环的 Web 端交互原型。

包含整改单列表（我派发的 / 我收到的 + 状态栏）、待我审批、新增整改整页表单、整改单详情（基础信息、派发信息、整改执行、验收意见与验收流程、倒序流转记录）、派单抽屉与多级验收（可通过 / 驳回，驳回可选驳回到发起或指定已流转节点）。

在线预览：`https://erisanne.github.io/safety-management-prototype/cross-org-rectification/`

## 原型包含的交互

- 首页轮播、隐患/整改/巡检/作业四个应用入口
- 首页不汇总展示待办，也不显示待办总数、最新待办列表或数字角标
- 待办由 APP 聚合各业务模块待处理单据，不依赖统一消息待办
- 待办中心按「隐患 / 整改 / 巡检 / 作业」四个模块组织，不设「全部」汇总模块
- 隐患：待我派单
- 整改：待我派单、待我接单、待我整改、待我验收
- 巡检：待我领取、待我巡检
- 作业：待我审批、待气体检测、待我作业
- 已办列表保留流程轨迹，用于回溯，默认展示近 6 个月
- 待办页标题栏提供搜索入口，支持按单号与事项名称跨模块模糊匹配
- 页面在手机视口内滚动

本轮不做消息模块。

## 说明

页面中的编号、人员、时间均为演示数据。业务结论以合同、已确认需求和签字验收为准，原型不代表正式结论。
