# 安全作业移动端原型（在线预览）

本仓库仅用于发布可点击的 HTML 原型，全部为模拟数据，不含正式需求、合同、验收资料或真实人员信息。

## 页面

- `index.html`：安全作业移动工作台
- `inspection-crossday.html`：巡检计划跨天任务时间

## 原型包含的交互

- 首页轮播、隐患/整改/巡检/作业四个应用入口
- 首页只展示最新三条待办，完整待办在「待办」页
- 待办两级结构：第一层「待办 / 已办」，第二层「全部 / 隐患整改 / 作业 / 巡检」
- 已办列表保留流程轨迹，用于回溯，默认展示近 6 个月
- 待办页标题栏提供搜索入口，支持单号与事项名称模糊匹配
- 底部导航的「待办」显示红色数字角标
- 页面在手机视口内滚动

本轮不做消息模块。

## 说明

页面中的编号、人员、时间均为演示数据。业务结论以合同、已确认需求和签字验收为准，原型不代表正式结论。
